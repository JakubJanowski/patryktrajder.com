Description

Weld large structures without owning a huge table. The dWS01 mobile extension is a project designed to solve the biggest problem of small workshops – not having enough space to work on long elements such as gates or frames. This is an original design featured on Mateusz Doniec’s channel, refined with the support of a technologist with 20 years of experience, so you can build it at a low cost while maintaining professional precision.

Why choose the dWS01 project?

When you buy this product, you receive complete documentation (DXF and PDF files) for building a modular support extension that offers:

  • Dimensions 2400x200 mm: An ideal working surface for long profiles, frames, and gate structures.

  • Full mobility: Thanks to its own wheel system, after finishing work you can roll the extension against the wall and recover valuable workshop space.

  • Compatible with System 16/28: The documentation includes plans for both hole standards – match the project to your existing tooling.

  • Material flexibility: The project is prepared for 10, 12, or 15 mm plates. You decide on the stiffness level and the budget.

  • "Like building blocks" assembly: Precise DXF files for laser cutting make the build simple, fast, and free from the need for specialist machinery.

What does this project include?

  • Precise DXF files: Ready for laser cutting and designed to minimize material waste.

  • Detailed assembly guide (PDF): A clear step-by-step manual to help you prepare and assemble all parts.

  • Complete material list: A detailed specification of plate thicknesses and steel grades required to build the full set.

  • Technical documentation and 3D views: Clear assembly drawings that make production and installation easier.

Why is this project worth choosing?

  • Verified in real workshop use: Every part of this project has been tested and proven useful in Mateusz Doniec’s workshop.

  • Workshop-proven solutions: The design was created based on real needs and real experience from welding table work.

  • Everything in one place: DXF, PDF, material list, and technical drawings — everything you need to build the set.

  • A fraction of the market price: Building these tools yourself saves thousands of PLN compared to buying ready-made products.

  • Time savings: You receive ready-to-use documentation that helps you prepare parts for production and assembly much faster.

ℹ️ Digital Product (DIY Plans)

This product is digital documentation (a complete set of build plans for the tooling project). It is not a physical accessory set or finished metal parts. Proper execution of this project requires basic welding skills and ordering steel parts to be cut (for example by laser or plasma) according to the attached DXF files.
